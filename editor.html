Wybierz produkt, opcjonalnie wklej własne URL-e zdjęć i odpal edytor. Projekt zostanie utworzony przez backend na sales-demo-pbx2.

Personalization
Plik trafi do Vercel Blob → publiczny URL → przekazany do edytora jako personalizedPresentationContent.components.customerImage1.
Manual config (advanced)

Wpisz parametry instancji i odpal edytor ręcznie — przydatne do testowania innych instancji niż sales-demo-pbx2.

Instance
Z podkreśleniami (np. masterpiece_ai), nie myślnikami. To jest <site_name> w URL-u JS CDN. Wymaga whitelistowania domeny po stronie Printbox.
Editor Config
Musi być friendly-url slug (np. hoodie-black), nie numeryczne ID. Resolve: GET /api/ec/v4/products/{id}/ → friendly_url.
Pre-filled Attributes (opcjonalne)
Nie przekazuj przy wznawianiu projektu (projectId ustawiony).
